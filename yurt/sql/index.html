Qanday ishga tushiriladi
  1. Kerakli fayl yonidagi «Nusxalash» tugmasini bosing — butun fayl nusxalanadi.
  2. Pastdagi tugma bilan Supabase SQL Editor'ni oching (yurt-school loyihasi).
  3. Bo'sh oynaga qo'ying (Ctrl + V yoki telefonda bosib turib «Вставить / Paste») va Run ni bosing.
  4. Pastda natija jadvali chiqsa — tayyor. Qizil xato chiqsa, skrinshot qilib yuboring.
